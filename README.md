# Cognitive Transport Protocol (CTP)

Cognitive Transport Protocol (CTP) is a frozen v1.0 reference specification defining a Layer-8 control standard for AI–human information flow.

## Canonical Specification
The normative, authoritative specification is:
- `/rfc/RFC-CTP-2026-01.md`

This document is frozen and defines all required protocol semantics, invariants, and compliance criteria.
